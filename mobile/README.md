# تطبيق نور للجوال (React Native + Expo)

تطبيق المرضى والأطباء. يعمل على نفس خادم نور ونفس الحسابات والملفات الموجودة في الموقع.

## التجربة على جوالك عبر Expo Go

1. ثبّت تطبيق **Expo Go** على جوالك من App Store أو Google Play.
2. على الكمبيوتر ثبّت **Node.js 22** من nodejs.org.
3. افتح الطرفية (Terminal) واكتب الأوامر التالية، واحداً بعد الآخر:

```bash
git clone https://github.com/pacskkgh-alt/noor.git
```

```bash
cd noor/mobile
```

```bash
npm install
```

```bash
npx expo start --tunnel
```

4. سيظهر رمز QR في الطرفية:
   - **آيفون:** امسحه بكاميرا الجوال.
   - **أندرويد:** امسحه من داخل تطبيق Expo Go.

التطبيق يتصل افتراضياً بالخادم الحقيقي `https://noor-yzbg.onrender.com`. للتجربة على خادم محلي:

```bash
EXPO_PUBLIC_API_URL=http://192.168.1.10:3000 npx expo start
```

## الشاشات

- الدخول والتسجيل واستعادة كلمة المرور، مع رمز التحقق بالجوال.
- **المريض:** ملفاتي، وتفاصيل الفحص، وعارض الأشعة الاحترافي، ورفع الفحوصات (كاميرا، صور، ملفات)، والمشاركات، وحسابي.
- **الطبيب:** الفحوصات الواردة، وتفاصيل الفحص مع العارض بكامل أدواته.
- العربية من اليمين لليسار، والإنجليزية من اليسار لليمين.

## ملاحظات

- **عارض الأشعة** هو نفس عارض الموقع (Cornerstone3D)، يُفتح داخل التطبيق بنفس الحساب عبر رابط مؤقت يُستخدم مرة واحدة.
- **الإشعارات الفورية (Push)** لا تعمل داخل Expo Go، فهذا قيد من Expo. تحتاج نسخة مبنية من التطبيق (Development build أو نسخة المتجر).
- **رفع قرص أشعة كامل (CD)** يتم من الموقع على الكمبيوتر.
