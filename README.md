# نور | Noor

منصة لرفع الفحوصات الطبية وحفظها ومشاركتها مع الأطباء والمراكز الصحية (نموذج أولي).

## التشغيل

```bash
npm install
npm start
```

بعدها افتح المتصفح على: http://localhost:3000

لوحة الإدارة لها رابط مستقل: http://localhost:3000/admin

## الحسابات التجريبية

| النوع | البريد | كلمة المرور |
|---|---|---|
| مريض | patient@noor.app | Patient@1234 |
| طبيب موثّق | doctor@noor.app | Doctor@1234 |
| طبيب بانتظار التوثيق | mona@noor.app | Doctor@1234 |
| مدير (من رابط `/admin` فقط) | admin@noor.app | Admin@1234 |

لإعادة البيانات التجريبية من البداية: `npm run reset` ثم `npm start`.

## المزايا

- **المريض**: يرفع ملفات PDF والصور وأشعة DICOM والفيديو، ويصنّفها ويبحث فيها، ويعرضها داخل الموقع، ويقرأ ملاحظات الطبيب.
- **الرفع**: موافقة على الشروط قبل أول رفع، ومراجعة الملفات بصور مصغّرة قبل الرفع، ثم شريط تقدّم وعلامة ✓ أو ✗ لكل ملف.
- **الضغط**: الصور تُضغط على الخادم بجودة عالية مع الحفاظ على أبعادها (وتُزال منها بيانات الموقع)، والفيديو يُضغط بصيغة H.264 في الخلفية. لا يُحفظ الناتج إلا إذا كان أصغر بوضوح، وملفات DICOM لا تُضغط أبداً.
- **الأشعة**: رفع دراسة CT أو MRI كاملة، أو مجلد قرص المستشفى، حتى لو كانت الملفات بلا امتداد. تُجمع الصور في بطاقة لكل سلسلة وتُرتَّب، والعارض يتصفح المقاطع بعجلة الفأرة أو السحب أو الشريط أو الأسهم. تحميل الدراسة يكون كملف ZIP.
- **المشاركة**: مع طبيب موثّق أو مركز من الدليل أو أي شخص، عبر واتساب أو البريد أو برابط فقط. لكل مشاركة رابط خاص ورمز دخول من 4 أرقام ومدة صلاحية، ويُقفل الرابط بعد 5 محاولات خاطئة. يرى المريض سجل كل من فتح الرابط، ويستطيع إلغاء المشاركة.
- **الطبيب**: يسجّل ويرفع رخصته، وبعد توثيقه تصله الفحوصات ويكتب ملاحظاته عليها.
- **المدير**: صفحة دخول مستقلة على `/admin` (لا يدخل منها غيره، ولا يدخل هو من الصفحة العامة)، وإحصائيات، وإدارة المستخدمين (إيقاف وحذف)، وتوثيق الأطباء، ودليل المراكز الصحية، وسجل النشاط.
- **اللغة**: العربية والإنجليزية، ويعمل على الجوال.

## التحقق بالجوال (Authentica)

المرضى والأطباء يتحققون برمز SMS عند إنشاء الحساب، وعند كل تسجيل دخول، وعند استعادة كلمة المرور، وعند تغيير رقم الجوال. الأدمن والحسابات التجريبية معفاة.

| المتغير | الوصف |
|---|---|
| `AUTHENTICA_API_KEY` | مفتاح API من لوحة Authentica (إلزامي للإرسال الحقيقي) |
| `AUTHENTICA_TEMPLATE_ID` | رقم قالب الرسالة في Authentica (اختياري) |
| `AUTHENTICA_BASE_URL` | الافتراضي `https://api.authentica.sa/api/v2` |

- **بدون مفتاح** تعمل المنصة في «وضع تجريبي»: يظهر الرمز على الشاشة ولا تُرسل أي رسالة.
- **مدة صلاحية الرمز** 5 دقائق، وإعادة الإرسال بعد 60 ثانية، و5 محاولات خاطئة كحد أقصى.
- **حدود الإرسال:** 5 رسائل لكل رقم و20 رسالة لكل عنوان IP في الساعة.
- **صيغة الأرقام:** تُقبل الأرقام السعودية بصيغة `05XXXXXXXX` أو `+9665XXXXXXXX`، وتُحفظ بالصيغة الدولية.

## البنية

- `server.js`: الخادم (Node.js + Express)
- `lib/store.js`: التخزين (ملف JSON في `data/`) والبيانات التجريبية
- `lib/otp.js`: رموز التحقق بالجوال وإرسالها عبر Authentica
- `lib/media.js`: التعرف على الملفات، وقراءة DICOM، وضغط الصور (sharp) والفيديو (ffmpeg)، وملفات ZIP
- `lib/samples.js`: توليد الملفات التجريبية (تقرير PDF، أشعة صدر، أشعة مقطعية للرأس من 48 مقطعاً)
- `public/`: الواجهة (`app.js` الصفحات، `viewer.js` عارض الملفات و DICOM، `i18n.js` الترجمة، `styles.css` التصميم)
- `data/uploads/`: الملفات المرفوعة

## قبل الإطلاق الفعلي

- استبدال ملف JSON بقاعدة بيانات (مثل PostgreSQL)، والملفات بتخزين سحابي مشفّر (مثل S3)
- تفعيل HTTPS وتشفير الملفات المخزّنة
- ربط واتساب (WhatsApp Business API) وخدمة بريد للإرسال التلقائي. حالياً يفتح الموقع واتساب أو البريد برسالة جاهزة.
- دعم صيغ DICOM المضغوطة (JPEG/JPEG2000) في العارض
- ضغط الفيديو يستهلك المعالج، لذا يحتاج خطة استضافة أقوى من المجانية
- استعادة كلمة المرور، والتحقق بخطوتين، والالتزام بأنظمة حماية البيانات الصحية المحلية
