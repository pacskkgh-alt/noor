# نور | Noor

منصة لرفع الفحوصات الطبية وحفظها ومشاركتها مع الأطباء والمراكز الصحية (نموذج أولي).

## التشغيل

```bash
npm install
npm start
```

بعدها افتح المتصفح على: http://localhost:3000

## الحسابات التجريبية

| النوع | البريد | كلمة المرور |
|---|---|---|
| مريض | patient@noor.app | Patient@1234 |
| طبيب موثّق | doctor@noor.app | Doctor@1234 |
| طبيب بانتظار التوثيق | mona@noor.app | Doctor@1234 |
| مدير | admin@noor.app | Admin@1234 |

لإعادة البيانات التجريبية من البداية: `npm run reset` ثم `npm start`.

## المزايا

- **المريض**: يرفع ملفات PDF والصور وأشعة DICOM والفيديو، ويصنّفها ويبحث فيها، ويعرضها داخل الموقع، ويقرأ ملاحظات الطبيب.
- **المشاركة**: مع طبيب موثّق أو مركز من الدليل أو أي شخص، عبر واتساب أو البريد أو برابط فقط. لكل مشاركة رابط خاص ورمز دخول من 4 أرقام ومدة صلاحية، ويُقفل الرابط بعد 5 محاولات خاطئة. يرى المريض سجل كل من فتح الرابط، ويستطيع إلغاء المشاركة.
- **الطبيب**: يسجّل ويرفع رخصته، وبعد توثيقه تصله الفحوصات ويكتب ملاحظاته عليها.
- **المدير**: إحصائيات، وإدارة المستخدمين (إيقاف وحذف)، وتوثيق الأطباء، ودليل المراكز الصحية، وسجل النشاط.
- **اللغة**: العربية والإنجليزية، ويعمل على الجوال.

## البنية

- `server.js`: الخادم (Node.js + Express)
- `lib/store.js`: التخزين (ملف JSON في `data/`) والبيانات التجريبية
- `public/`: الواجهة (`app.js` الصفحات، `viewer.js` عارض الملفات و DICOM، `i18n.js` الترجمة، `styles.css` التصميم)
- `data/uploads/`: الملفات المرفوعة

## قبل الإطلاق الفعلي

- استبدال ملف JSON بقاعدة بيانات (مثل PostgreSQL)، والملفات بتخزين سحابي مشفّر (مثل S3)
- تفعيل HTTPS وتشفير الملفات المخزّنة
- ربط واتساب (WhatsApp Business API) وخدمة بريد للإرسال التلقائي. حالياً يفتح الموقع واتساب أو البريد برسالة جاهزة.
- دعم صيغ DICOM المضغوطة (JPEG/JPEG2000) والدراسات متعددة الملفات في العارض
- استعادة كلمة المرور، والتحقق بخطوتين، والالتزام بأنظمة حماية البيانات الصحية المحلية
